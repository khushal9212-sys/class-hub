# 📚 Class Hub

A student-run class archive for sharing notes, syllabus, question papers, announcements, and important dates. Built with Flask + Supabase, deployed on Render.

🔗 **Live site:** https://class-hub-13q1.onrender.com

---

## ✨ Features

- 📁 **Subject-wise file organization** — Notes, Syllabus, Question Papers, Answers, General
- 📅 **Important Dates** — Upcoming tests and assignments with attachments
- 📢 **Announcements** — Latest class updates on the homepage
- 📊 **Polls** — Create and vote on class polls
- 🔐 **Admin panel** — Protected delete and management tools
- 🔎 **Duplicate detection** — Files are hashed so the same file can't be uploaded twice
- 🎨 **Modern UI** — Dark theme with glassmorphism and animated gradients

---

## 🛠️ Tech Stack

| Layer | Tech |
|---|---|
| Backend | Flask (Python) |
| Database | Supabase (PostgreSQL) |
| File Storage | Supabase Storage |
| Frontend | Jinja2 templates + vanilla CSS |
| Deployment | Render |
| Version Control | Git + GitHub |
